# 💚 HISSA

### Kharcha baanto, hisaab rakho.

**HISSA** is a modern shared expense management platform designed to make group expenses simple, transparent, and stress-free.

Whether it's a trip with friends, shared rent, roommates, family expenses, or everyday group spending — HISSA helps users track who paid, who owes, and how everything should be settled.

## 👥 Group Expense Management

Users will be able to create and manage shared expense groups.

Examples:

- 🏖️ Trip with friends
- 🏠 Flat / roommates
- 👨‍👩‍👧 Family expenses
- 🎉 Events
- 🍕 Dinner groups
- 💼 Team expenses

Each group can have its own members, expenses, balances, and settlements.

---

## 💰 Expense Tracking

HISSA is designed to support flexible expense tracking.

Users will be able to:

- Add expenses
- Edit expenses
- Delete expenses
- Assign participants
- Track who paid
- Track who owes
- Add expense descriptions
- Categorize expenses
- View expense history

---

## 🧮 Smart Expense Splitting

Different situations require different ways to split an expense.

HISSA is planned to support:

- Equal split
- Exact amount split
- Percentage split
- Shares-based split
- Custom split

The goal is simple:

> **Enter the expense once. Let HISSA handle the math.**
